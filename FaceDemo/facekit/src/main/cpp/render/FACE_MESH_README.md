# 基于 Delaunay 三角剖分的瘦脸实现方案

本文档详细介绍了 `FaceMeshRender` 的技术实现原理。本方案采用 **基于特征点的动态三角剖分 (Feature-based Dynamic Delaunay Triangulation)** 技术，通过构建贴合人脸结构的非均匀网格来实现精准的瘦脸变形。

## 1. 方案概述

与规则网格（Regular Grid）方案不同，本方案不再使用固定的矩形网格，而是根据每帧检测到的人脸关键点动态生成三角形网格。

**核心思想**：
*   **特征对齐**：网格顶点直接对应人脸关键点（如脸颊、下巴边缘），使得变形操作能精确作用于特定部位。
*   **动态拓扑**：随着人脸移动或表情变化，网格结构会实时更新（重新剖分），确保持续贴合。
*   **背景融合**：通过引入屏幕边界点和辅助点，确保人脸区域与背景区域平滑过渡，避免出现空洞。

**代码位置**: 
- 渲染器: `facekit/src/main/cpp/render/FaceMeshRender.cpp`
- 算法库: `facekit/src/main/cpp/utils/Delaunay.hpp`
- 调试器: `facekit/src/main/cpp/render/DelaunayDebugRender.cpp`

## 2. 网格生成流程 (Mesh Generation)

网格生成分为三个步骤，在每一帧渲染时动态执行：

### 2.1 点集收集 (Point Collection)
为了构建完整的覆盖屏幕的网格，我们收集以下三类点（共约 110-120 个点）：
1.  **人脸关键点 (Landmarks)**: 98 个 PFLD 关键点。这些点定义了人脸的内部结构和轮廓。
2.  **屏幕角点 (Screen Corners)**: `(0,0), (1,0), (0,1), (1,1)`。确保网格覆盖整个画布四角。
3.  **边界中点 (Edge Midpoints)**: 屏幕四边的中点。防止生成跨度过大的狭长三角形，提高插值质量。

### 2.2 Delaunay 三角剖分
使用 **Bowyer-Watson 算法** 对收集到的点集进行三角剖分。
*   **输入**: 归一化的 2D 点集 `[0, 1]`。
*   **输出**: 三角形顶点索引列表 (Indices)。
*   **特性**: Delaunay 剖分保证了生成的三角形尽可能接近“等边”，避免了极度狭长的三角形，从而保证纹理插值的视觉质量。

### 2.3 缓冲区更新 (Buffer Update)
*   将点集转换为 OpenGL 顶点数据 (Position NDC `[-1, 1]`, TexCoord `[0, 1]`)。
*   使用 `GL_DYNAMIC_DRAW` 将顶点数据 (VBO) 和索引数据 (IBO) 上传至 GPU。

## 3. 瘦脸变形原理 (Vertex Warping)

变形逻辑在 **Vertex Shader** 中执行，利用“引力场”模型对网格顶点进行位移。

### 3.1 变形算法
对于网格中的每一个顶点 `V`（其实就是人脸关键点或背景点）：

1.  **身份识别**: Vertex Shader 接收顶点坐标。由于顶点直接对应关键点，我们可以通过距离判断该顶点是否属于“左脸颊”或“右脸颊”区域。
2.  **引力计算**:
    *   **目标**: 脸部中心（鼻尖/面中）。
    *   **源头**: 脸颊边缘关键点。
    *   如果顶点位于脸颊影响半径内，计算其受到的向心力。
3.  **位移应用**: `Position_New = Position_Old + Direction * Intensity * Weight`。
    *   `Weight` 由距离决定（`smoothstep`），距离脸颊边缘越近，变形越强。

### 3.2 效果优势
*   **精准控制**: 变形直接作用于定义脸型的关键点上，效果比操作无关的规则网格点更直接。
*   **连贯性**: 背景点（如屏幕角点）不受变形力影响（距离太远），通过 Delaunay 三角形的连接，脸颊的变形会平滑过渡到静止的背景，实现自然的拉伸。

## 4. 调试工具 (DelaunayDebugRender)

为了验证剖分结果，提供了 `DelaunayDebugRender` 类。
*   **功能**: 以线框模式 (GL_LINES) 绘制生成的三角形网格。
*   **视觉反馈**:
    *   **红点**: 参与剖分的顶点。
    *   **绿线**: 三角形边。
*   **用途**: 检查网格是否正确覆盖人脸，以及是否存在异常狭长的三角形。

## 5. 性能考量

| 指标 | 规则网格方案 | Delaunay 动态网格方案 |
| :--- | :--- | :--- |
| **CPU 开销** | 极低 (一次性生成) | **中等** (每帧计算三角剖分) |
| **GPU 开销** | 低 (顶点数固定 ~4000) | 极低 (顶点数少 ~120) |
| **显存带宽** | 低 | **中等** (每帧上传 VBO/IBO) |
| **变形质量** | 平滑，但非特征对齐 | **精准，特征对齐** |
| **适用场景** | 低端机、简单液化 | 高端机、复杂换脸/美妆 |

本方案虽然增加了每帧 CPU 的计算负担（三角剖分），但换取了物理意义更明确的网格结构，特别适合需要纹理与五官精确贴合的场景。
